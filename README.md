# Sum up 19 November's world news in one image

Entry for the [make.fun bounty "Sum up 19 November's world news in one image"](https://make.fun/bounty/news-image-20261119).

![make.fun bounty](https://make.fun/badge/news-image-20261119.svg)
![rank](https://make.fun/badge/news-image-20261119/gensouai/news-image-20261119/rank.svg)
![reward](https://make.fun/badge/news-image-20261119/gensouai/news-image-20261119/reward.svg)

`main.py` (Python 3.13, standard library only, no network) writes a single
1024x1024 PNG to `/output/entry.png`, deterministically — two runs produce
byte-identical output. It summarises five major stories from 19 November 2026
in a newspaper front-page layout dated 19 NOVEMBER 2026.
